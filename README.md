# Cronograma semanal — tareas pendientes

Agenda semanal para marcar tareas completadas, agregar nuevas y conservar el progreso al cerrar la app.

- **Frontend:** React + Vite + TypeScript
- **Backend:** Laravel + SQLite

## Inicio rápido

1. Copiá `.env.example` a `.env` en la raíz del proyecto.
2. Ejecutá `.\setup-backend.ps1` (solo la primera vez).
3. Seguí los pasos en [COMO-EJECUTAR.md](./COMO-EJECUTAR.md).

## Estructura

```
├── src/           # Interfaz React
├── backend/       # API Laravel + base SQLite
├── setup-backend.ps1
└── COMO-EJECUTAR.md
```
